# 参考画布自动适配当前输出

提供者声明的宽高是稳定的逻辑参考画布，不是用户显示器的物理分辨率。游戏模式渲染器每帧读取 MangoApp 当前输出尺寸，以参考画布计算统一等比缩放，并把宽高比多出的方向扩展为逻辑输出视口。根锚点依附当前输出视口边缘，所有内容裁剪到实际输出。

平台不提供手工输出分辨率设置。手工值会复制 Gamescope 已知状态，在切换外接屏、显示模式或未来多输出场景后失效，也会把渲染器细节泄漏给提供者。若后续需要用户调整视觉大小，应增加独立的全局界面缩放策略，不修改提供者参考画布。

提供者文字使用与系统统计字体分离的高密度栅格。输出缩放只改变最终文字尺寸，不再直接放大 MangoHud 为原始字号生成的低密度字形。
